zxcmodule
Binary module for Garry's Mod providing low-level access to engine internals — prediction, animation, network channel, and ConVar manipulation.
Author: serejaga
x64 Client-state Cheat Module
lua
require("zxcmodule")

-- Remove cheat protection from a ConVar
ded.ConVarSetFlags("mat_fullbright", 0)

-- Disable entity interpolation
ded.SetInterpolation(false)

-- Disable animation sequence interpolation
ded.SetSequenceInterpolation(false)

-- Hook into CreateMove
hook.Add("PreCreateMove", "example", function(cmd)
ded.SetBSendPacket(false) -- choke packet
end)
